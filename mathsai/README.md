# MathsAI

Automated KS3/KS4 Edexcel mathematics teaching system for a single teacher — lesson planning, worked examples, and tiered practice questions, generated by Claude and cached in SQLite to control API cost.

This README is a stub that will grow with each implementation phase (see `CLAUDE.md` for the full 9-phase roadmap). Phase 1 delivers the project scaffold, database schema, and curriculum seed only — no AI generation, frontend, or deployment yet.

## Status: Phase 1 — Project Scaffold

Implemented:
- FastAPI backend skeleton with SQLAlchemy models for all five tables (`topics`, `lesson_cache`, `question_cache`, `teaching_log`, `regeneration_log`)
- Alembic migrations, starting from `0001_initial_schema`
- Full KS3/KS4 Edexcel curriculum taxonomy, seeded on first run (no AI calls)
- `GET /api/topics` — the only working route so far

Not yet implemented: AI generation, caching logic, lesson/questions/progress/export routes, frontend, Docker, auth, PDF export, CI. See `CLAUDE.md` for the phase-by-phase plan.

## Tech stack (Phase 1)

- Python 3.11, FastAPI, Uvicorn
- SQLite via SQLAlchemy (WAL mode enabled)
- Alembic for migrations
- `python-dotenv` for local `.env` loading

## Local setup

```bash
cd mathsai/backend
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd ..
cp .env.example .env   # fill in ANTHROPIC_API_KEY when Phase 2 needs it

cd backend
alembic upgrade head
uvicorn main:app --reload
```

Then visit `http://localhost:8000/api/topics` to confirm the full curriculum list loads.

## Model note

`CLAUDE.md` originally specified `claude-sonnet-4-6`, which is not a valid Anthropic model ID. This project uses **`claude-sonnet-5`** instead, wherever the AI service is implemented (Phase 2 onward).

## Network access

This system is intended to run privately over Tailscale (or an equivalent WireGuard mesh) rather than public hosting — no password-based auth is planned. See `CLAUDE.md` → Production Hardening → Network access and authentication.
